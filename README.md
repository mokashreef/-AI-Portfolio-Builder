**AI Portfolio Builder** هو منصة احترافية تتيح لك إنشاء موقع "Portfolio" شخصي متكامل ومتجاوب في دقائق معدودة، وبدون الحاجة لكتابة سطر كود واحد!

---

## ✨ المميزات الرئيسية

* **🎨 3 قوالب احترافية مذهلة**: اختر القالب الذي يعبر عن هويتك المهنية (Modern, Creative, Professional).
* **⚡ معاينة حية (Live Preview)**: شاهد التغييرات التي تجريها على موقعك تحدث في الوقت الفعلي أثناء تعديل البيانات.
* **📱 متجاوب 100%**: تصميمات متوافقة تماماً مع أجهزة سطح المكتب، الأجهزة اللوحية، والهواتف الذكية.
* **📦 التصدير والتحميل**: أنشئ موقعك ثم قم بتحميله كملف `ZIP` لرفعه على أي استضافة خاصة بك بكل سهولة.
* **🔒 حسابات شخصية**: قم بإنشاء حساب لإدارة وحفظ التعديلات على الـ Portfolio الخاص بك في أي وقت.
* **🌍 رابط عام للاستعراض**: احصل على رابط مخصص يمكن مشاركته مباشرة مع أصحاب العمل أو العملاء.
* **🌙 استايلات متميزة**: الاهتمام بأدق التفاصيل مثل تأثيرات الـ Glassmorphism، الوضع المظلم (Dark Mode)، والخطوط العصرية.

## 🎨 القوالب المتوفرة

1. **Modern Minimal 🎯**: تصميم نظيف، عصري، بألوان هادئة ومساحات بيضاء واسعة، مناسب جداً للمصممين والكتاب.
2. **Creative Developer 🚀**: خلفية داكنة مع ألوان نيون وتأثيرات Glassmorphism مذهلة، مثالي للمبرمجين ومطوري الويب.
3. **Professional Corp 💼**: تصميم فخم بألوان الأزرق الداكن (Navy) والذهبي يشبه السيرة الذاتية (CV) الاحترافية الموجهة للشركات.

## 🛠️ التقنيات المستخدمة

تم بناء المشروع باستخدام تقنيات الويب الأساسية للحصول على أفضل أداء وتوافقية:
* **Frontend**: HTML5, CSS3, Vanilla JavaScript
* **Backend**: PHP 
* **Database**: MySQL (عبر ملف دوال PHP لتسجيل وإدارة المستخدمين)

---

## 🚀 كيفية التثبيت والتشغيل محلياً (Localhost)

اتبع الخطوات التالية لتشغيل المنصة على جهازك الشخصي:

1. قم بتحميل وتثبيت بيئة خادم محلي مثل **XAMPP** أو **Laragon**.
2. قم بنسخ مجلد المشروع بالكامل وضعه داخل مجلد الويب الخاص بالخادم (مثلاً `htdocs` في XAMPP أو `www` في Laragon).
3. (في حال إرفاق قاعدة بيانات لاحقاً) قم بإنشاء قاعدة بيانات جديدة واستيراد ملف الـ SQL.
4. قم بتشغيل الخادم (Apache و MySQL) من لوحة تحكم XAMPP/Laragon.
5. افتح المتصفح الخاص بك وقم بزيارة الرابط التالي:
   ```text
   http://localhost/-AI-Portfolio-Builder-main
   ```
